# MateCaña Deli Grocery

Bilingual (English/Spanish) website for MateCaña Deli Grocery in the South Bronx.

## Business information

- **Address:** 911 E 156th St, Bronx, NY 10455
- **Phone and WhatsApp:** (347) 577-5999
- **Hours:** Daily, 7:00 AM–9:00 PM

## Website pages

- Home
- Food Menu
- Groceries
- Order for Pickup
- About Us
- Contact, Hours and Directions

## Website features

- Responsive mobile-friendly design
- English/Spanish language switch
- Storefront banner photograph
- Food and grocery category pages
- Phone and WhatsApp pickup ordering
- Google Maps directions
- GitHub Pages-ready static website

## Before final launch

The menu items and prices shown are provisional examples. Replace them with the store's confirmed menu and prices before advertising online ordering.

## Publish with GitHub Pages

Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
