# MateCaña Bodega

Bilingual (English/Spanish) storefront for MateCaña Bodega — Breakfast & Lunch Express.

## Features

- Responsive neighborhood-store design
- English/Spanish language switch
- Filterable breakfast, lunch, and essentials menu
- Working shopping cart
- WhatsApp order handoff
- Phone and contact section
- Ready for GitHub Pages

## Update before launch

The current phone number is **(347) 577-5999** and the address is **911 E 156th St, Bronx, NY 10455**. Add confirmed opening hours, final products, and final prices in `index.html`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
